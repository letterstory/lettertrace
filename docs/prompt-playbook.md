# Prompt playbook

Everything below comes from live runs against two real clients on 2026-07-26/27:
**Cloudflare** (huge, decades of authority) and **Runlayer** (MCP-security startup,
out of stealth Dec 2025). ~110 queries against Claude Opus 4.8 and GPT-4o with web
search on, ~$15 of provider spend.

It exists because the first pilot produced a result none of us expected, and the
reason took four experiments to isolate.

---

## The one rule

**A monitored prompt only measures something if the answer names companies.**
That is not the same as the prompt being about the right subject, and it is not
what a buyer would naturally type.

| Prompt shape | Companies named per answer | Client hit rate |
|---|---|---|
| "List the top 5 companies…" / "Rank the leading vendors **by name**" | **3.7** | **50%** |
| "Who are the main players in X?" | 2.5 | 0% |
| "Give me a shortlist with names" | 0.8 | 0% |
| "How do I…" / "What's the best X for Y?" / "Which vendors offer X?" | ~0.1 | 0% |

Measured on Runlayer; each row is 8–24 queries across both providers.

The trap is that the bottom row reads like exactly what a real person would ask.
The model answers it *well* — with an explanation of the category — and names
nobody. The run succeeds, the answer is good, the measurement is empty.

**"Give me a shortlist" is the sharpest trap of all.** It sounds like a request
for names and returns advice on how to choose. It scored worse than the vague
"who are the main players", which at least names a few.

### Write prompts like this

```
List the top 5 companies selling <category>, with a one-line description of each.
Name the specific vendors that sell <product>. Just the company names.
Rank the leading <category> providers by name.
Which companies provide <capability>? Just the company names.
```

### Not like this

```
How do I set up <thing>?                      → explainer, no names
What's the best <category> for <use case>?    → explainer, no names
Which vendors offer <thing>?                  → surprisingly, still no names
Give me a shortlist for <category>            → advice on shortlisting
How should I evaluate <category>?             → advice on evaluating
```

Lettertrace's generator was rewritten to follow this (`VARIATION_SYSTEM` in
`lib/llm/index.ts`), so auto-generated prompts now come out in the right shape.
If you write prompts by hand, this is the rule to follow.

## What the two clients showed

|  | Cloudflare | Runlayer |
|---|---|---|
| Mention rate | **19/20 (95%)** | **1/20 (5%)** in the first pilot |
| Claude | 10/10 | 1/10 |
| ChatGPT | 9/10 | 0/10 |
| Where in the answer | first sentences | buried near the end |

**Cloudflare hits on anything.** Every prompt shape worked, including the ones
that fail for everyone else. A brand with that much authority will look good on
day one regardless of how you configure it — which also means it tells you
nothing about whether your configuration is any good.

**Runlayer is the honest test**, and its misses are real: web search ran on 19 of
its 20 queries. The models went and looked, and still didn't name them. Across
all 66 Runlayer queries in every experiment, they were named 4 times (~6%).

Their one clean win in the first pilot was:

> *"How do I set up a governed MCP gateway for Claude, Cursor, and ChatGPT?"*

That looked like proof that specificity was the answer. **It wasn't.** Re-running
the identical prompt on the identical model missed. A single hit is noise — which
is exactly why runs now report a confidence interval (see below).

## Every prompt used

### Cloudflare — auto-generated from cloudflare.com

Four topics, generated by the app from the scraped site. `[Claude|ChatGPT]`.

**CDN & Web Performance**
```
[HIT |HIT ] What's the best CDN to speed up a global website?
[HIT |HIT ] How can I reduce latency for users in different regions?
[HIT |HIT ] Which content delivery networks have the most global points of presence?
```
**DDoS Protection & Web Security**
```
[HIT |HIT ] What are the best services to protect a website from DDoS attacks?
[HIT |HIT ] How can I add a web application firewall to my site?
[HIT |miss] My site is under attack right now, what tools can help mitigate it?
```
**Edge Computing & Serverless**
```
[HIT |HIT ] What are the best serverless platforms for running code at the edge?
[HIT |HIT ] How do I deploy functions close to my users to reduce latency?
```
**DNS & Domain Management**
```
[HIT |HIT ] What is the fastest managed DNS provider available?
[HIT |HIT ] Where should I register a domain with good security features?
```

Competitors the app suggested: Akamai, Fastly, Amazon CloudFront, Google Cloud
CDN, Microsoft Azure Front Door, Imperva, Vercel, NS1. Observed frequency across
the run: Akamai 10, Fastly 9, CloudFront 9, Google Cloud CDN 6, Imperva 4,
Vercel 4, NS1 1, Azure Front Door 1.

### Runlayer — auto-generated from runlayer.com

```
[miss|miss] What tools can help my company govern and secure AI agents across different teams?
[miss|miss] How can we discover shadow AI usage from unmanaged agents and plugins in our company?
[miss|miss] What is the best way to manage MCP servers across a large organization?
[miss|miss] What platforms help enterprises roll out AI agents to employees safely?
[miss|miss] How do enterprises control what AI agents are allowed to access and do?
[miss|miss] What tools give visibility into which employees are using AI agents and MCPs?
[HIT |miss] How do I set up a governed MCP gateway for Claude, Cursor, and ChatGPT?
[miss|miss] How can non-technical employees create governed AI coworkers without security reviews for each one?
[miss|miss] What's the best platform for enforcing security policies on AI agents at scale?
[miss|miss] How do I monitor and track AI spend and adoption across teams?
```

Every one of these is a reasonable question. Nine of ten measured nothing.

### Experiment 1 — does specificity matter? (no)

Varied three things independently: naming the protocol (MCP), naming the client
tools (Claude/Cursor/ChatGPT), and the question frame. 12 prompts × 2 providers.

```
[miss|miss] How do I set up a governed MCP gateway for Claude, Cursor, and ChatGPT?
[miss|miss] What's the best MCP gateway for governing Claude, Cursor, and ChatGPT across a company?
[miss|miss] Which vendors offer MCP gateways that govern Claude, Cursor, and ChatGPT?
[miss|miss] How do I set up a governed MCP gateway across my company?
[miss|miss] What's the best MCP gateway for governing AI tools across a company?
[miss|miss] Which vendors offer MCP gateways for enterprise governance?
[miss|miss] How do I govern and secure the AI tool connections used by Claude, Cursor, and ChatGPT at my company?
[miss|miss] What's the best platform to govern AI tool connections for Claude, Cursor, and ChatGPT?
[miss|miss] Which vendors offer governance and security for AI tool connections used by Claude, Cursor, and ChatGPT?
[miss|miss] How do I govern and secure AI agent tool connections at my company?
[miss|miss] What's the best platform for governing and securing AI agents at an enterprise?
[miss|miss] Which vendors offer governance and security for enterprise AI agents?
```

**0 for 24.** All three factors: 0%. Naming the protocol didn't help. Naming the
tools didn't help. The frame didn't help — including "Which vendors offer X",
which sounds like it asks for names and doesn't.

### Experiment 2 — does demanding a list matter? (yes)

Same client, same week. 8 prompts × 2 providers, graded by how explicitly each
demands company names. `vendors=` counts companies named per answer.

```
tier=explicit
[miss|HIT ] vendors=4/4  List the top 5 companies selling MCP security and governance products, with a one-line description of each.
[miss|miss] vendors=4/4  Name the specific vendors that sell MCP gateways for enterprises. Just the company names and what each is known for.
[HIT |HIT ] vendors=3/3  Rank the leading MCP security startups by name.

tier=shortlist
[miss|miss] vendors=3/0  Which specific companies should I evaluate for MCP security? Give me a shortlist with names.
[miss|miss] vendors=0/0  I'm building a vendor shortlist for AI agent governance. Which companies should be on it?
[miss|miss] vendors=2/0  Give me a vendor shortlist for governing MCP servers across a company.

tier=players
[miss|miss] vendors=3/1  Who are the main players in MCP security for enterprises?
[miss|miss] vendors=4/2  What companies compete in the MCP gateway space?
```

Runlayer: **3/6 in the explicit tier, 0/10 everywhere else.**

> **Statistical honesty:** 3-of-6 vs 0-of-10 is about p≈0.04 by Fisher's exact
> test. Strong enough to write prompts by, not strong enough for a client deck
> without a confirmatory run.

### Experiment 3 — the rewritten generator

Given only the topic *"MCP security and governance for enterprise AI agents"*,
the updated generator produced:

```
[miss] vendors=4  List the top companies providing MCP (Model Context Protocol) security and governance solutions for enterprise AI agents. Just the company names.
[miss] vendors=3  Name the specific vendors that offer runtime security and access control for AI agent tool-calling and MCP servers.
[miss] vendors=2  Which companies provide governance, audit logging, and policy enforcement for enterprise AI agents? Just the company names.
[miss] vendors=2  Rank the leading providers of AI agent identity and authentication management by name.
[miss] vendors=3  Who are the main players securing MCP deployments in enterprises?
[miss] vendors=4  What's the best platform for monitoring and controlling AI agent access to internal data and APIs?
```

**3.0 companies named per answer, up from ~0.1.** Runlayer still didn't appear —
and that's the point. A miss now means *"three competitors were named and we
weren't"* instead of *"nobody was named"*. The first is competitive intelligence;
the second is a wasted run.

## Reading a result

### A zero is not automatically a finding

Three different things produce a 0% mention rate, and they need opposite responses:

| What you see | What it means | What to do |
|---|---|---|
| 0%, `informativeRate` low | The answers named nobody. The prompts are the wrong shape. | Rewrite the prompts |
| 0%, wide confidence interval | Too few answers to tell. 0-of-1 spans 0–79%. | Run more / raise replicates |
| 0%, `informativeRate` high, tight interval | Competitors were named and the client wasn't. **A real finding.** | Brief this to content |

`informativeRate` and the interval are both on the run report (`quality` and
`summary.brandMentionRateInterval`).

### Answers vary between identical calls

The same prompt on the same model hit once and missed on a re-run. An identical
ChatGPT call returned 0, 1, 3, then 2 sources on four tries. At a true 50% rate,
a single ask reads zero **half the time**.

`replicates` on a project asks each prompt up to 10× per run. Default is 1
(nothing changes silently); raising it multiplies token cost linearly. For a
client where you're watching for a first mention, 3 is a reasonable floor.

### Two currencies: named vs cited

These are separate events won by different content.

- The how-to gateway question **cited runlayer.com as a source while naming
  nobody at all.**
- The list questions that *did* name companies cited roundup articles, **not any
  vendor's own site.**
- Even Cloudflare — named in 6 of 6 answers in a later test — had
  `cloudflare.com` cited in only 1 of 6.

For a young client this matters more than the mention rate: *"the model read your
article while answering this"* is real, demonstrable progress in the months
before a mention lands. It's the **Cited your site** card on the overview and the
`citations` block on the run report.

Practically: technical docs and how-to content win **citations**; getting into
third-party roundups and listicles wins **names**.

## Don't trust the auto-suggested competitors

For Runlayer the app proposed: Portkey, Cloudflare AI Gateway, Lasso Security,
Prompt Security, Zenity, Witness AI, Nightfall AI.

Who actually showed up across 16 answers:

```
 10  MintMCP          3  Runlayer          1  Zenity
  9  TrueFoundry      3  Lasso Security    1  Obsidian Security
  4  Operant          2  Kong / Okta       1  Natoma / Noma Security
```

**Only Lasso appeared on both lists.** The two companies that dominate the
category in AI answers — MintMCP and TrueFoundry — were never suggested.
`suggestCompetitors` draws on the model's prior, which for a fast-moving category
produces plausible-sounding names rather than real rivals.

**So: run once, read the answers, then set the competitor list from who actually
appeared.** Don't accept the suggestions blind.

## Onboarding a client — checklist

1. **Set the brand and every domain.** Index 0 is the primary; the rest are
   phantom sites. All of them count for citation tracking.
2. **Write prompts that demand named companies.** Use the generator, or the
   shapes at the top of this doc. Reread each one and ask: *would a good answer
   to this contain company names?*
3. **Run once with placeholder competitors**, read the answers, then set the real
   competitor list from what appeared.
4. **Check `informativeRate` before anything else.** If the answers aren't naming
   companies, the mention rate is meaningless and the prompts need rewriting.
5. **For a low-authority client, set `replicates` to 3+** so a zero means
   something and a first mention isn't noise.
6. **Track citations, not just mentions.** For anyone below Cloudflare-tier
   authority it's the number that moves first.
7. **Expect months.** Poll `GET /v1/projects/:id/history` — `firstMentionAt` is
   the event worth alerting on.

## Reproducing any of this

`scripts/pilot-client.ts` runs the whole pipeline against a live brand without
writing to the database. Add an entry to `CLIENTS` and:

```bash
npx tsx scripts/pilot-client.ts <key> --max-prompts 10 --providers anthropic,openai
```

A 40-query pilot across two clients cost about $3.80.
